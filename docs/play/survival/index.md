# Survival

A vanila-like survival world with an econonmy and land claming.

Supports 1.8-26.2 on Java Edition and Bedrock Edition.

## How to play:

1. Open Minecraft Bedrock Edition or Java Edition. *Use any version, we support 1.8-26.2. 26.2 is prefered for native compatbility.*
2. On Java Edition and supported Bedrock platforms, simply enter the IP `play.minersonline.uk` as a server. Or follow the [Using Geyser with Consoles](https://geysermc.org/wiki/geyser/using-geyser-with-consoles/) guide.
3. Once added, just join the server. Then select the Survival button in the lobby menu.
