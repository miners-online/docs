# City World

A creative server about building realistic cities, with energy, automation, and computer mods.

Supports only 26.2 on Java Edition with Fabric. Mods are required.

## How to play:

1. Install the required mods
2. Open Minecraft Java Edition 26.2
3. On Java Edition simply enter the IP `play.minersonline.uk` as a server.
3. Once added, just join the server. Then select the City World button in the lobby menu.
