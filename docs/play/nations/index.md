# Nations

Nations is our game mode focused around building and managing your own nation.

Supports versions 1.8-26.2 on Java Edition and the latest versions of Bedrock Edition.

## Features

1. Standard survival gameplay
2. Land claiming and protection
3. Player-driven economy
4. Shops and trading
5. Government and politics

:::warning In development
The following features are still in development and are not yet available to players:
1. Land claiming and protection
2. Player-driven economy
3. Shops and trading
4. Government and politics
:::

## Getting Started

To get started, follow these steps:

1. Download and install a supported version of Java Edition or Bedrock Edition.
2. Launch Minecraft
3. Connect to the server using the IP: `play.minersonline.uk`. For console platforms follow the [Using Geyser with Consoles](https://geysermc.org/wiki/geyser/using-geyser-with-consoles) guide.
4. Select the "Nations" game mode from the lobby and start building your nation!
